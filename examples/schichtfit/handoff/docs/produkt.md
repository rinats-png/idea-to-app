# Produkt

Schichtfit schlägt Schichtarbeitern Trainingseinheiten vor, die zu ihrem Dienstplan passen.

| ID | Funktion | Priorität |
|---|---|---|
| F-01 | Konto anlegen und anmelden | Muss |
| F-02 | Dienstplan eintragen | Muss |
| F-03 | Trainingsvorschläge passend zum Plan | Muss |
| F-06 | Training abhaken und Verlauf ansehen | Muss |
| F-04 | Erinnerung vor einer Einheit | Soll (später, E-004) |
| F-05 | Daten exportieren | Kann (später, E-004) |

Zielgruppe: Erwachsene im Wechselschichtdienst. Die Vorschläge sind allgemeine Anregungen, keine medizinische Beratung (A-003, offen).
