# Start & Einstellungen

| Einstellung | Wert |
|---|---|
| Einstieg | Neue Idee |
| Erfahrung | Einsteiger |
| Arbeitsweise | Geführt |
| Umfang | Lite (Phasen 0, 1, 3, 5, 6, 8, 11, 13, 14, 21, 22; Phase 19 vorgezogen) |
| Plattform | Web-App (PWA) |
| Risikostufe | 2 |

**Begründung Stufe 2:** Es gibt Nutzerkonten und Dienstpläne. Ein Dienstplan verrät, wann jemand nicht zu Hause ist – das ist mehr als „harmlos“, aber keine Gesundheitsdaten, keine Zahlung, kein genauer Standort. Im Zweifel gilt die höhere Stufe; Stufe 3 trifft hier nicht zu.

**Zeit und Kosten:** Lite braucht grob 1–2 Sitzungen (siehe guides/zeit-und-kosten.md). Die Befehle `weiter`, `erklär das`, `status`, `pause` wurden erklärt.

**Vor Veröffentlichung für andere** nachzuholen: Phasen 12, 16, 19 (hier bereits erledigt), 20 und 23.
