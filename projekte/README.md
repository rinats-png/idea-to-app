# projekte/

Hier legt die KI für jede App-Idee einen eigenen Ordner an, z. B. `projekte/meine-app/`. Darin liegen der Projektstatus, das Entscheidungs-Log, ein Dokument pro Phase, die Mockups und am Ende das Übergabepaket (`handoff/`).

Aufbau und Regeln: siehe [`AGENTS.md`](../AGENTS.md) Abschnitt 3.

> **Privatsphäre:** Wenn du dieses Repository öffentlich auf GitHub hast, sind auch deine Projektdateien öffentlich. Für eigene Ideen am besten über **„Use this template“** ein **privates** Repository anlegen – oder Projektordner per `.gitignore` ausschließen (siehe Kommentar in `.gitignore`).
